# PLANT 3D 편집기

석유화학 플랜트의 배관·장치를 클릭으로 3D 모델링하고, 라인별 ISO 도면과 BOM·가스켓 목록을 뽑는 프로그램입니다.
설치형 웹앱(PWA)이라 주소로 접속해 바탕화면에 앱으로 설치할 수 있고, 인터넷이 끊겨도 실행됩니다.

---

## 1. 처음 한 번: 저장소 만들고 배포하기

1. https://github.com/new 에서 저장소를 만듭니다.
   - Repository name: `plant3d`
   - **Public** 선택 (무료 GitHub Pages 조건)
   - Create repository
2. 만든 저장소 화면에서 **uploading an existing file** 을 누르고, 이 폴더 안의 파일과 폴더를 **전부** 끌어다 놓습니다.
   - `.github` 폴더도 꼭 포함해야 자동 배포가 됩니다. (윈도우 탐색기에서 보이지 않으면 "숨긴 항목" 표시를 켜세요.)
   - 아래쪽 **Commit changes** 클릭
3. 저장소의 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
4. **Actions** 탭에서 "Deploy PLANT 3D"가 초록색 체크가 되면 완료입니다. (1~2분)
5. 접속 주소: `https://<GitHub 아이디>.github.io/plant3d/`

## 2. 앱으로 설치하기

- **PC (Chrome/Edge)**: 위 주소에 접속 → 주소창 오른쪽의 설치 아이콘(⊕) → 설치
- **휴대폰/태블릿**: 브라우저 메뉴 → "홈 화면에 추가"

설치 후에는 바탕화면 아이콘으로 실행되고, 인터넷이 없어도 열립니다.

## 3. ISO 도면을 3D로 바꾸기

1. 상단 **ISO 첨부** → **파일 추가**로 ISO 도면(PDF 또는 이미지)을 올립니다.
2. 처음 한 번 **AI 설정**에서 Anthropic API 키를 저장합니다.
   - 키 발급: console.anthropic.com → API Keys (사용량만큼 과금, 도면 1장 수백 원 수준)
   - 키는 이 기기 브라우저에만 저장되고, 도면 이미지는 판독할 때만 Anthropic으로 직접 전송됩니다.
   - **회사 도면을 외부 AI 서비스로 보내도 되는지 사내 규정을 먼저 확인하세요.**
3. 도면 카드의 **AI로 3D 변환**을 누르면 1~3분 뒤 **확인표**가 열립니다.
   - 왼쪽에 원본 도면, 오른쪽에 구간(Run)별 항목(엘보·플랜지·밸브·티·레듀서·계기·끝)과 거리가 나옵니다.
   - **노란 줄**은 AI가 추정한 값, **빨간 줄**은 3D로 만들 때 문제가 있는 항목입니다.
   - 거리는 바로 앞 기준점(시작점, 엘보 꺾이는 점, 플랜지 조인트, 티 중심, 밸브 중심)부터의 길이입니다. 도면 치수를 그대로 넣으면 됩니다.
4. **3D에 반영** → **ISO 보기**로 원본과 비교하고, 틀린 곳은 표에서 고쳐 다시 반영합니다. (다시 반영하면 이전 결과는 자동으로 지워집니다.)
5. 확인표는 도면 파일에 같이 저장되므로 나중에 **확인표 열기**로 이어서 고칠 수 있습니다.

AI를 쓰지 않을 때는 **빈 확인표로 직접 입력**으로 같은 표에 직접 입력해서 3D를 만들 수 있습니다.
직접 3D로 그린 모델은 부품을 선택하고 **이 라인 ISO 도면**으로 언제든 ISO를 볼 수 있습니다.

## 4. 데이터 관리 (중요)

- 작업 내용은 **이 PC의 이 브라우저**에 자동 저장됩니다.
- 상단 **데이터 저장/불러오기** 에서
  - **파일로 저장**: `PLANT3D_날짜_시간.p3d.json` 백업 파일을 내려받습니다. 정기적으로 백업하세요.
  - **파일 열기(전체 교체)**: 백업 파일로 복원하거나 다른 PC로 옮길 때 사용합니다.
  - **모델 파일 추가**: 현재 작업에 다른 모델(예: 도면을 읽어 만든 라인)을 덧붙입니다.
- **회사 도면·현장 데이터 파일(.p3d.json, PDF)은 저장소에 올리지 마세요.** 저장소가 공개(Public)라 누구나 볼 수 있습니다. `.gitignore`에 이 파일들을 제외하도록 적어 두었습니다.

## 5. 업데이트 방법

업데이트를 올리면 사용 중인 앱 하단에 **"새 버전이 준비되었습니다 · 지금 업데이트"** 알림이 뜹니다. 누르면 바로 새 버전으로 바뀝니다. 작업 데이터는 그대로 유지됩니다.

### Claude에게 맡기는 경우 (권장)
1. Claude 대화에서 "plant3d 저장소 연결해서 ○○ 기능 추가해줘"라고 요청합니다.
2. Claude가 코드를 고치고 `version.js` 숫자와 `CHANGELOG.md`를 올린 뒤 저장소에 반영합니다.
3. 1~2분 뒤 자동 배포되고 앱에 업데이트 알림이 뜹니다.

### 직접 하는 경우
1. 파일을 고칩니다 (주로 `index.html`).
2. `version.js` 의 숫자를 올립니다. 예: `'1.0.0'` → `'1.0.1'`
   - **이 숫자를 올려야** 설치된 앱이 새 버전을 알아챕니다.
3. `CHANGELOG.md` 맨 위에 무엇을 바꿨는지 적습니다.
4. GitHub 저장소에 고친 파일을 올립니다 (Add file → Upload files).

### 되돌리기
GitHub 저장소의 **History(커밋 기록)** 에서 이전 버전을 확인하고 되돌릴 수 있습니다. 되돌린 뒤에도 `version.js` 숫자는 올려야 앱에 반영됩니다.

## 6. 폴더 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 프로그램 본체 (화면·3D·ISO 생성) |
| `iso2d3d.js` | ISO 도면 → 3D 변환 (AI 판독·확인표·3D 생성기) |
| `version.js` | 버전 번호 (업데이트 때마다 올림) |
| `CHANGELOG.md` | 버전별 변경 이력 |
| `sw.js` | 오프라인 실행·새 버전 감지 |
| `pwa.js` | 앱 설치·업데이트 알림 화면 |
| `manifest.webmanifest`, `icons/` | 앱 이름·아이콘 |
| `vendor/` | 3D(three.js r128)·PDF(pdf.js 3.11.174) 라이브러리 |
| `.github/workflows/deploy.yml` | 저장소에 올리면 자동 배포 |
